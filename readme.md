# بازی فردا (Farda Snake Game)

**نسخه:** 1.0  
**سازندگان:** علیرضا امجدی و صدرا عبدی  
**سال ساخت:** 2025 / 1404

---

### معرفی بازی  
بازی فردا یک بازی دو نفره مار است که باید با خوردن غذا مار خود را بزرگ کنید. بازیکنان باید مراقب باشند به دیوارها و یا مار حریف برخورد نکنند.  
آخرین بازیکنی که زنده بماند برنده است.

---

### کنترل‌ها  
**بازیکن 1:**  
- بالا: کلیدهای جهت‌نما (↑)  
- پایین: کلیدهای جهت‌نما (↓)  
- چپ: کلیدهای جهت‌نما (←)  
- راست: کلیدهای جهت‌نما (→)  

**بازیکن 2:**  
- بالا: W  
- پایین: S  
- چپ: A  
- راست: D  

---

### فایل‌ها  
- `farda.py` : کد اصلی بازی  
- `high_scores.json` : فایل ذخیره امتیازات برتر
