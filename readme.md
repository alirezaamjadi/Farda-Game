# Farda Game Installation Guide 🎮🐍

---

### 📦 Contents of Installation Package  
- Compressed file `farda_game.rar`  
- Main game file `farda.py`  
- High scores file `high_scores.json`  
- This installation guide `README_install.md`

---

### 🔑 Extraction Password  
The password to extract the archive:  
`amjadifardagame`

---

### 🛠️ Installation and Running Steps

1. Extract the `farda_game.rar` archive using software like WinRAR or 7-Zip.  
2. When prompted, enter the password: `amjadifardagame`  
3. After extraction, open the extracted folder and ensure `farda.py` is present.  
4. Make sure Python 3 and Pygame library are installed on your system.  
5. Run the game using the command:  
   ```bash
   python farda.py
   ```  
6. Enjoy the game! 🎉

---

### 📝 Important Notes  
- This is a two-player game; controls can be viewed in the game menu.  
- High scores are saved in the `high_scores.json` file.  
- For questions or support, please contact the developers.
